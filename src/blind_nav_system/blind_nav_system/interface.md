상태

LOCKED

READY

NAV

1. LOCKED -> READY

조건:

버튼 1번

의미:

안내 시작 대기

“어디로 안내해 드릴까요?” 같은 질문을 함

2. READY -> LOCKED

조건:

아무 말도 안 하고 일정 시간 timeout

의미:

사용 의사가 없다고 보고 종료

3. READY -> NAV

조건:

사용자가 목적지 말함

GPT가 **“~로 안내할까요? 맞으면 버튼을 눌러 주세요”**라고 확인

버튼 누름

즉,

목적지 발화

확인 질문

버튼 확인
이 3단계가 있어야 NAV

4. NAV -> LOCKED

조건:

목적지 도착

의미:

안내 종료

5. NAV -> PAUSED

조건:

버튼 1번
또는

손잡이 당기기 신호

의미:

주행 중 일시정지

중요:

예전처럼 NAV에서 버튼으로 바로 LOCKED 가는 게 아니라,

반드시 PAUSED로 감

6. PAUSED -> NAV

방법은 두 가지야.

경우 A. 재개

조건:

PAUSED 상태에서 버튼 1번

시스템이 “다시 이동할까요? 맞으면 버튼을 눌러 주세요”

버튼 한 번 더 누름

즉 버튼-확인-버튼으로 재개

경우 B. 새 목적지를 직접 말한 경우

조건:

PAUSED에서 사용자가 새 목적지를 직접 말함

예: “편의점 가자”, “3호로 바꿔”

시스템이 “~로 변경할까요? 맞으면 버튼을 눌러 주세요”

버튼 누름

그러면 바로 NAV

7. PAUSED -> READY

조건:

사용자가 변경 의사만 말함

예: “목적지 바꾸고 싶어”, “다른 데 가고 싶어”

시스템이 “목적지를 변경하시겠습니까? 맞으면 버튼을 눌러 주세요”

버튼 누름

의미:

바로 목적지 확정은 안 하고

다시 목적지를 새로 듣는 상태로 감

8. PAUSED -> LOCKED

조건:

사용자가 종료 의사 말함

예: “종료해줘”, “그만해줘”, “안내 끝”

시스템이 “안내를 종료할까요? 맞으면 버튼을 눌러 주세요”

버튼 누름

의미:

안내 완전 종료

한 번에 보면

흐름은 거의 이렇게야.

LOCKED
  └─ 버튼 → READY

READY
  ├─ timeout → LOCKED
  └─ 목적지 말함 + 확인 후 버튼 → NAV

NAV
  ├─ 도착 → LOCKED
  └─ 버튼 or 당기기 → PAUSED

PAUSED
  ├─ 버튼 + 확인 버튼 → NAV
  ├─ 새 목적지 직접 말함 + 확인 버튼 → NAV
  ├─ 변경 의사 말함 + 확인 버튼 → READY
  └─ 종료 의사 말함 + 확인 버튼 → LOCKED
핵심 포인트

PAUSED에서 제일 중요한 구분은 이거야.

“다른 곳 가고 싶어”
→ 변경 의사만 있음
→ READY

“편의점으로 바꿔”
→ 새 목적지가 이미 있음
→ NAV

“종료해줘”
→ LOCKED

버튼 누르고 다시 버튼 누름
→ NAV

원하면 내가 이걸 바로 상태도 그림처럼 표로 정리해서 다시 써줄게.
