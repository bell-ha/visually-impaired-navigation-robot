# floor_points — 층별 호실 좌표 찍기

지도 위에서 호실 좌표(x, y, 방향)를 찍어 `config/location.yaml`에 넣는 도구 묶음.
2026-11-11 층별 지도 도입 때 111곳(1층 12 · 2층 17 · 3층 27 · 4층 27 · 5층 28)을 이걸로 찍었다.
절차 요약은 `docs/NAVIGATION.md` 2.5.

```
make_map_pdf.py ──▶ 지도 PDF (+ .geo.json) ──▶ 사람이 펜으로 표시
                                                   │
make_point_tool.py ◀───────────────────────────────┘
        │  HTML 한 장 (브라우저에서 클릭 · 드래그)
        ▼
   JSON 저장 ──▶ import_points.py ──▶ 검사 ──▶ location.yaml (--apply)
```

| 파일 | 하는 일 |
|---|---|
| `common.py` | 지도 읽기, 로봇 모양 벽 검사, 엘리베이터 기준점, yaw → 쿼터니언 |
| `make_map_pdf.py` | 층별 A3 PDF + 쪽마다 지도 칸 위치(`.geo.json`) |
| `make_point_tool.py` | PDF 그림 + 벽 거리 지도를 넣은 클릭 도구 HTML (약 3 MB) |
| `point_tool_template.html` | 그 HTML의 틀 (`__DATA__` 자리에 데이터가 들어간다) |
| `import_points.py` | JSON → 이름 정리 · 검사 → YAML 미리보기 / `--apply`로 반영 |
| `data/` | 2026-11-11 판: 사람이 표시한 PDF, 그 PDF의 칸 위치, 내보낸 JSON |

필요한 것: `numpy scipy pillow pyyaml matplotlib`, `pdftoppm`(poppler). 한글 글꼴은 mac 기본 또는 `fonts-nanum`.

## 원리

**1. 그림 픽셀 ↔ 지도 좌표.**
`make_map_pdf.py`는 쪽마다 지도 칸이 종이 어디에 있는지(`pos` = 왼쪽 · 아래 · 폭 · 높이, 종이 비율)와
그 칸이 몇 m부터 몇 m까지 그리는지(`xl`, `yl`)를 `.geo.json`에 적는다.
`set_aspect('equal')`이 칸을 줄이므로 **그린 뒤에** 잰다. 클릭 도구는 이 값으로 선형 변환한다.

```
x = xl0 + (px − 칸왼쪽) / 칸폭 × (xl1 − xl0)
y = yl1 − (py − 칸위)   / 칸높이 × (yl1 − yl0)      (그림은 아래로 갈수록 py 증가)
```

펜 표시는 그림 위에 덧그리는 것이라 변환에 영향이 없다. **쪽 크기를 바꾸거나 잘라 내면 틀어진다.**
큰 지도와 엘리베이터 확대 그림 둘 다 클릭할 수 있다(확대 쪽이 더 정밀).

**2. 방향.**
클릭만 하면 0°(지도 +x, 그림 오른쪽). 8 px 이상 드래그하면 끈 방향 = 도착 후 로봇이 바라보는 방향.
yaml에는 `z = sin(yaw/2)`, `w = cos(yaw/2)`로 들어간다(로봇은 수평, `coord_util.py`와 같은 규약).

**3. 벽 검사 — 로봇 + 뒤따르는 사용자 모양.**
Nav2 footprint `[[0.175,-0.175],[0.175,0.475],[-0.9,0.475],[-0.9,-0.175]]` + padding 0.08
→ 앞 0.255 · **뒤 0.98** · **왼쪽 0.555** · 오른쪽 0.255 m. 뒤 꼬리는 손잡이를 잡은 사람 자리다.
층 지도마다 "가장 가까운 벽까지 거리"(EDT, cm)를 미리 계산해 PNG 빨강 채널에 담고(모름 칸은 초록 채널),
모양 안을 5 cm 간격으로 훑어 최소값을 본다.

| 색 | 조건 |
|---|---|
| 초록 | 모양-벽 ≥ 10 cm 이고 중심-벽 ≥ 50 cm |
| 주황 | 둘 중 하나 미달 |
| 빨강 | 모양이 벽 칸이나 지도 밖에 닿음 |

Nav2가 도착 직전에 회전하므로 빨강이면 도착 자세에서 꼬리가 벽에 걸려 목표 근처에서 맴돌 수 있다.
예전 5층 506~512호(방향 0°)가 이 경우였다 — 왼쪽이 북쪽 벽에 닿았고, 서쪽을 보게 다시 찍어 해결.
같은 검사를 `import_points.py`가 파이썬으로 **다시** 한다(브라우저 결과를 믿지 않음).
검사 규칙(`common.py` 값 ↔ HTML의 `D.fpb`/`D.warn`)은 한 곳에서 오므로 따로 고치지 말 것.

**4. 이름.**
`101` → `101호`, `316-1`/`316다시1` → `316다시1호`, `107(GS25)` → `107호(GS25)`,
`LAB`(504·520) → `(연구실)` 붙임, 숫자가 아닌 이름은 그대로.
`-` 대신 `다시`: 사람이 "삼백십육 다시 일호"라고 말하고, `interface.py`가 숫자 사이의 '다시'를
재개 명령이 아니라 방 이름으로 읽는다(2026-11-11 커밋 9eeb957).
층 번호와 방 번호 앞자리가 다르면 경고한다(실제로 5층에 '403', 3층에 '18'로 잘못 쓴 적 있음).

## 주의

- 좌표계는 **floor5 하나**다(1~4층 지도도 floor5 좌표계로 옮김, `tools/map_align`). 다른 좌표계 지도에 쓰지 말 것.
- 브라우저 자동 저장 이름은 `floorpts_v1`. 새 작업을 깨끗이 시작하려면 `--store-key`를 바꾼다.
- 찍은 좌표는 **지도 위 좌표**다. 로봇 실주행으로 확인하기 전까지는 사람이 옆에서 지켜본다.
- `--apply`는 `# ── 호실 좌표` 줄 아래 **전부**를 바꾼다. 일부 층만 고치려면 JSON에 전 층을 담아 넘긴다.
