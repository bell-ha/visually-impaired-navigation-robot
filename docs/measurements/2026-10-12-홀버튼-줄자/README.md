## 줄자 높이 → `lift` 환산

**실제로 눌러서 성공한 두 점**으로 오프셋을 구했다(= 줄자높이 − 그때의 lift):

```
2F ▲  줄자 99.9cm  ↔  성공 lift 0.944  →  5.5cm
5F ▼  줄자 99.3cm  ↔  성공 lift 0.933  →  6.0cm
                                   평균  5.75cm

lift(m) = (줄자높이cm − 5.75) / 100
```
